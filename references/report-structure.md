## 캠페인 구조

```
캠페인 "플레이스#1"          = 광고그룹 "새로필라테스"  = 플레이스 광고
캠페인 "새로필라테스 파워링크" = 파워링크 광고
```

집행 중인 파워링크 광고그룹 4개:
- 노원역필라테스 (최초 등록)
- 상계동필라테스 (8/31 등록)
- 노원키즈필라테스 (9/2 등록)
- 노원산전필라테스 (9/2 등록)

파워링크 키워드는 계속 늘어날 수 있다. 04번 표에 행을 추가하고, 06번에 요약 카드를
추가한다.

색상 매칭 고정: **플레이스 = 민트(#45ceb3), 파워링크 = 잉크(#1c2b2a)**.
모든 차트에서 일관되게 유지한다.

## KPI 요약

4개 타일: 총 노출수 / 총 클릭수 / 평균 클릭률 / 총 광고비
각각 sub 문구로 일 평균 또는 클릭당 평균 비용을 표시한다.

강조색: 총노출=mint(#45ceb3), 총클릭=mintDark(#2ea88f), 클릭률=진한틸(#1a5c4d),
광고비=ink. 카드 왼쪽 4px 강조선 + 우상단 라인 아이콘 + 원형 배경 장식.

## 01. 일별 추이

노출수 막대 + 총비용 라인의 콤보 차트(`dailyChart`).

- 막대(노출수) 라벨은 막대 **하단**, 선(총비용) 라벨은 선 **위쪽** — 겹침 방지
- 범례는 `bottom` 고정. top-right에 두면 마지막 날짜가 최고치일 때 라벨과 겹친다
- 차트 컨테이너: `<div class="scroll-x" style="overflow-x:auto;">` 안에
  `<div style="height:280px; min-width:{날짜수×80}px;">`. 최소 650px
- x축 ticks: `maxRotation:0, autoSkip:false`

### 인사이트 박스 (차트 카드 바로 아래)

특정 주간 패턴이 관찰될 때만 유지한다. 패턴이 사라지면 박스 자체를 빼는 것도 고려.

구성:
1. **① 일별 지표 통합표** — 날짜 / 노출 / 검색 / 콘텐츠 / 클릭 / CTR / CPC (최근 5일)
2. **② 플레이스 광고 평균노출순위** — 5칸 숫자 그리드.
   소제목에 `(06번의 파워링크 키워드 순위와는 다른 지표)` 반드시 병기.
   01번은 플레이스 광고 순위, 06번은 파워링크 키워드 순위로 대상이 다른데
   이름이 같아 혼동된 이력이 있다
3. **③ 해석 문장** — 구분선(`border-top`) 두고 `.note-mint`로

해석 문장은 매주 다시 쓴다. 표만 갱신하고 문장을 두면 사실과 어긋난다.
톤은 단정 대신 "가장 유력하게 보이는 해석" 수준으로 낮춘다.

표 2개를 따로 두지 말고 컬럼으로 합칠 것 — 원래 ①CTR·CPC표 + ②지면별표 두 개였는데
모바일에서 01번만 3~4화면을 차지해 통합했다. 앞으로도 길어지면 표를 늘리기보다
컬럼으로 합치는 쪽을 우선한다.

## 02. 광고 유형별 성과

파워링크 vs 플레이스. 좌측 막대(`groupChart`) + 우측 도넛(`costPie`).

도넛 조각 안에 흰 글씨로 "금액"과 "(비중%)"를 두 줄 표시. Chart.js datalabels에서
배열을 반환하면 자동 줄바꿈된다:

```js
formatter:(v,ctx)=>{ const total=...; const pct=...;
  return [v.toLocaleString()+'원', '('+pct+'%)']; }
```

도넛 title에 총 광고비를 넣는다: `광고비 비중 (총 79,329원)`

클릭수는 ×10 스케일 같은 배율을 쓰지 말고 실제 값 + 막대 끝 라벨로 표시한다.

## 03. 일별 광고비

파워링크 vs 플레이스, 날짜별 표. 2단 헤더 구조.

- 상단 헤더: 플레이스 / 파워링크 (각 3칸 colspan)
- 하단 헤더: 광고비 / 클릭 / CPC
- 맨 오른쪽 "합계" 컬럼은 rowspan으로 세로 병합
- 클릭 0인 날은 CPC를 `–`로 표기 (0으로 나누기 방지)
- 마지막 행은 전체 합계, 굵게. 집계 일수는 매주 다르다

원래 04번이었는데 2026.09.05에 03번으로 옮겼다. 02번이 유형별 성과이므로
유형별 일별 광고비가 바로 뒤에 오는 게 자연스럽다는 판단.

## 04. 캠페인 상세 지표

컬럼 9개 고정:
`광고 유형 / 광고그룹(키워드) / 노출수 / 클릭수 / 클릭률 / 총비용 / 평균CPC / 예산 비중 / 평균순위`

- **예산 비중**은 매주 `각 광고 총비용 ÷ 전체 광고비`로 재계산. 합이 100%인지 검산
- 신규 키워드 행에는 `(8/31 신규)` 같은 표기를 민트색 작은 글씨로 병기
- 평균순위는 파워링크에만 적용. 플레이스는 `—`
- CPC 값에 `.ctr-high`(민트 강조)를 **쓰지 말 것** — 07번에서 같은 색이
  "클릭률 4% 이상"을 뜻하므로 같은 색이 다른 의미로 쓰이면 혼동된다

표 아래에 CPC 해석 문구를 `.note-mint` + `.note` 2단으로 둔다.
플레이스 CPC와 파워링크 CPC를 대비시키되, **단정적으로 "파워링크로 옮겨라"라고
쓰지 말 것**. 두 광고의 성격 차이(플레이스=매장명·지도 검색이라 방문 의도가 더
뚜렷할 수 있음 / 파워링크=저렴하지만 클릭 절대량이 적음)를 같이 서술해 균형을 잡는다.

각주: 평균순위가 파워링크 전용 지표라는 점 + 제외 그룹이 OFF 상태여서 뺐다는 점
(그 그룹에 키워드 10개가 등록돼 있다는 사실 포함).

**새 지표를 추가할 때**: 표/카드를 새로 만들기 전에 이 표에 컬럼 하나를 추가하면
되는지 먼저 확인한다. 새 표를 만들면 같은 숫자를 두 곳에서 매주 갱신해야 하고
불일치가 생긴다. 실제로 중복 표를 만들었다가 되돌린 사례가 2건 있다.

## 05. 매체·기기별 분포

좌측 매체별 막대(`mediaChart`) + 우측 기기별 도넛(`deviceChart`).

- 매체 막대는 광고 유형별 색 구분 + 상단 범례
- 기기별 도넛은 PC/모바일 2조각이 아니라 **4조각**:
  플레이스·모바일=mint(#45ceb3) / 플레이스·PC=mintDark(#2ea88f) /
  파워링크·모바일=ink(#1c2b2a) / 파워링크·PC=연한잉크(#5b6b6a)
- 각 조각 안에 비중(%)을 흰 글씨로. 단 **5% 미만 조각은 라벨 생략**(겹침 방지)

Chart.js 다중 라벨은 `"\n"` 대신 배열로 쓴다: `['플레이스 광고','(새로필라테스)']`

## 06. 파워링크 키워드 노출순위 추이

라인 차트(`rankChart`) + 키워드 매칭 방식 비교표.

비교표는 직접 등록 키워드 vs 네이버 자동매칭(`-`)의 노출/클릭/순위/비용 대비.
자동매칭이 직접 등록보다 성과가 좋은 경향이 관찰되고 있어 확장검색 활용 검토
근거로 쓰인다.

### 신규 키워드 요약 카드

파워링크에 키워드가 추가되면 그래프+표 카드 밑에 요약 카드를 추가한다.

- **평균노출순위 + 코멘트만** 표시한다. 노출·클릭·총비용은 04번 표와 완전히 같은
  값이라 빼고, 코멘트 끝에 `(노출·클릭·비용은 04번 표 참고)`를 붙인다
- 데이터가 10일치 미만이면 이 카드로 유지. 충분히 쌓이면 `rankChart`처럼
  독립된 라인 차트로 승격
- 코멘트에 등록일과 며칠차인지 표기 (예: `(8/31 등록, 5일차)`)

## 07. 실제 검색어 분석

**데이터 출처 주의**: "검색어 보고서"는 파워링크 전용이 아니라 **플레이스+파워링크를
합친 계정 전체 데이터**다. 섹션 제목에 "— 파워링크"를 붙이지 말 것. 예전에 잘못
붙였다가 2026.09.02에 삭제한 이력이 있다.

레이아웃: 이 섹션 전용 `grid-2-07` 클래스(1.8fr:1fr) 사용. 일반 `grid-2`를 쓰면
좌측 표 컬럼이 찌그러진다. `.grid-2-07 > *{min-width:0;}`도 함께 필요하다.

### 좌측 카드

**(1) 정식 표** — 컬럼 순서 고정:
`검색어 / 매칭 / 노출 / 클릭 / 클릭률 / CPC / 총비용`
(CPC가 총비용보다 앞. "비용"이 아니라 반드시 "총비용"으로 표기)

- 클릭 2건 이상인 검색어만, 클릭수 내림차순, **개수 제한 없이 전부**
- 매칭 컬럼은 뱃지로: 일치=`<span class="tag tag-mint">일치</span>`,
  확장=`<span class="tag tag-ink">확장</span>`.
  "일치(유사검색어)"도 일치 계열이므로 민트 뱃지
- 클릭률 4% 이상인 행만 `<td class="num ctr-high">`. 표 하단에 범례 문구 포함

**(2) 클릭 1건 검색어** — 얇은 구분선 두고 컴팩트 목록.
`검색어(노출수회/총비용)` 형태로 한 줄 텍스트 나열. 경쟁사 브랜드명은 제외.

**(3) 노출은 있으나 클릭 0건인 검색어** — 또 구분선 두고 컴팩트 목록.
노출 5회 이상만, 노출수 내림차순, `검색어(N회)` 형태.
끝에 클릭 0 검색어 전체 건수·노출 합계를 각주로. 제외 키워드 검토 근거로 쓴다.

### 우측 카드

신규 키워드 등록 후보 태그 목록 + 설명 문구.

### 하단 전체 폭

경쟁사 브랜드명 검색어 표 (소재구 컬럼 포함). 정식 표나 클릭1건 목록에 넣지 말고
여기로 분리한다.

## 08. 상세지역 분석

시/군/구 단위 노출·클릭·비용 TOP 10 표 + 타겟 지역 합산 비중 콜아웃.

- `국내 - 상세 위치 확인불가` 행도 **삭제하지 말고 포함** (위치 미상 트래픽 규모 파악용)
- **TOP 10 밖에 클릭이 있는 지역은 컴팩트 목록으로 전부 표시.** 07번과 동일한
  누락 방지 원칙이다. 형식: `지역명(노출N·클릭N)` 클릭수 내림차순.
  끝에 클릭 0인 나머지 지역 수·노출 합계를 각주로
  (전면점검 전까지 TOP 10만 표시해 클릭 18건·전체의 20%를 누락했고, 타겟 지역인
  중랑구가 표에서 아예 안 보이는 문제가 있었다)
- 노출 합계가 KPI와 다르므로 "N회 차이" 각주를 매주 갱신

## 09. 시간대별 분석

`hourlyChart`, 0~23시 24개 시간대. 01번과 동일한 콤보 구조(막대+선, 양쪽 축).

- 막대(노출수, 좌축): 옅은 민트 `#cdeee7`, 라벨은 막대 안쪽 상단에 ink색
- 선(클릭수, 우축): mintDark. 라벨도 mintDark로 막대 라벨과 구분.
  **클릭 0인 시간대는 라벨 숨김** (`display: (ctx)=>data!==0`) — 노출 라벨과 겹침 방지
- 범례 하단(bottom)
- 가로 스크롤 wrapper + `min-width:650px` + `autoSkip:false` (24개라 모바일에서 겹침)

영업시간 내/외를 막대 색으로 구분하는 시도는 했다가 "통일해달라"고 되돌린 적 있다.
**색 구분을 다시 넣지 말 것.**

심야(22시~09시) 콜아웃은 노출·클릭·비중·비용을 매주 갱신. 심야 집행은 카카오톡·
네이버톡톡 상시 문의 대응 전략과 맞물린 의도된 운영이므로 "전략과 부합",
"놓치지 않음" 같은 긍정적 톤을 유지한다.

**최다 클릭 시간대는 매주 재계산할 것.** 고정된 값이 아니라 주마다 바뀐다
(8월엔 22시대였다가 9월 초 13~14시대로 이동한 사례).

노출 합계가 KPI와 다르므로 "N회 차이" 각주를 매주 갱신.

## 10. 검색 지면 vs 콘텐츠 지면

가로 막대 비교. 막대 끝에 실제 숫자 라벨.

콘텐츠 지면은 노출만 있고 클릭이 거의 없는 경향이 있다. 8/31에 매체 설정을
"검색 지면 · 네이버 및 검색 포털 매체"로 조정한 이력이 있다.

가로 막대는 `maintainAspectRatio:false`와 `maxBarThickness` +
`categoryPercentage`/`barPercentage` 조합을 쓴다. `barThickness` 고정값을 주면
좁은 컨테이너에서 막대가 겹친다.

## 11. 핵심 요약

잉크→진한틸 그라데이션 배경(`linear-gradient 135deg`) 인사이트 박스.
불릿 마커는 민트색 점.

**매주 전체를 다시 쓴다.** 지난주 문장을 두고 숫자만 바꾸면 사실과 어긋난다
(실제로 "노출이 계속 줄고 있다"가 다음 주 반등으로 거짓이 된 사례).

담는 내용: 예산 비중, 이번 주 두드러진 변화, 신규 키워드 관찰, 검색어 상위 성과,
자동매칭 vs 직접등록, 제외 그룹, 모바일 비중, 최고치 날짜, 지역 도달률, 시간대 패턴.

표에는 못 넣었지만 알아둘 만한 관찰(애매한 경쟁사 후보 등)은
`(참고)` 항목으로 여기 짧게 언급하는 방식을 쓸 수 있다.

## 12. 다음 액션

체크리스트형 실행 항목. 완료된 항목은 `<span class="tag tag-ink">✓</span>`로 표시하고
결과를 굵게 명시한다. 진행 중인 항목은 민트 번호 뱃지.

이 표에는 `.wide-table`을 붙이지 않는다 — 컬럼이 2개뿐이고 본문이 길어
`nowrap`이 걸리면 안 되는 표다.

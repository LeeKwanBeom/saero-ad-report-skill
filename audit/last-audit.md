# saero-ad-report 스킬 점검 기준선

이 파일이 기준선(정본)이다. 다음 점검 때 **신규 진단보다 먼저** 아래 항목을
`해결됨` / `미해결` / `근거없음` 으로 판정한 뒤에 새 항목을 추가한다.

채택 기준: 지적은 **파일 경로 · 줄 번호 · 원문 인용**이 있어야 채택한다.
결함(지금 틀린 것)과 개선안(더 나아질 수 있는 것)은 섞지 않는다.
실측한 것과 코드를 읽고 추론한 것을 구분해 표기한다.

## validate.py 검사 생존 확인 [실측]

합성 CSV(클릭 110)로 기준 PASS를 만든 뒤 각각 깨뜨려 FAIL 확인:

- 01번 5.22%에서 `.ctr-high` 제거 → FAIL(불일치 1건)
- 01번 3.37%에 `.ctr-high` 추가 → FAIL(불일치 1건)
- 01번 섹션 주석 변조로 셀 0건 유도 → FAIL(0건 가드 동작)
- 07번 `name-cell` 클래스 변조로 행 0건 유도 → FAIL(0건 가드 동작)

**0건 가드를 이번에 추가했다.** 이전에는 마크업이 바뀌어 정규식이 0건 매칭이면
조용히 PASS가 났다. 이제 셀·행 0건은 FAIL이다.

직전 회차에서 확인된 나머지 검사(태그 짝, 07번 클릭 합계, 시간대별 합계,
빈 CSV·1행 CSV 크래시 없음)는 그대로 유효.

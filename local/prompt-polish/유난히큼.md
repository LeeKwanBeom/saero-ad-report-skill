## 답 모양 둘

- **묻는 답('유난히 큼')** — 맨 위 줄 "유난히 큼 — 워크플로 검증을 권합니다, 약 n분. 돌릴까요?" → 걸린 조건 한 줄(① ② ③ 중 무엇이 왜) → 찾은 사실 한두 줄 → 추천(돌리기)과 이유 한 줄. 상자 · 기준별 비교 · 모델 · 설정 · 정하실 것은 쓰지 않는다 — 검증 뒤 상자를 주는 답에서 쓴다(그 답의 맨 위 줄은 "크기: 유난히 큼 — 워크플로 검증 반영 (걸린 것 : …)"). 작업이 여럿이면 다른 작업의 상자 · 기준별 비교 · 모델 · 설정은 그대로 쓰고 묻는 덩어리를 답 맨 끝에 둔다(마지막 줄 = 추천 줄).
- **준비 세션 추천 답** — 맨 위 줄 "크기: 유난히 큼 — 준비 세션을 권합니다" → 찾은 사실 한두 줄 → 새 세션(`D:\saero` 로 연 Code 탭)에서 칠 말 한 줄("스킬에 기능 추가하고 싶어 — <이름> : <목표 한 줄>" 처럼) + 그 준비 세션의 모델 · effort(Opus 5.5 · high · 울트라코드 끔 — 작업 알고리즘 2절 '조정') → 이유 한 줄이 마지막. `/clear` 가 든 줄을 끝에 두지 않는다.
